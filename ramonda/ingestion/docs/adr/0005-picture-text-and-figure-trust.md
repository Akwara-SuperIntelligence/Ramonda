# Picture text is never the document's own prose, and no number is asserted without a dataset

**Status:** accepted

The ten CAC49 pictures enter the chunk stream as ordinary text, filtered only by a 120-character novelty check, so `"Share of edible-oil supply (%) 100 80 60 40 20 0 Kenya 36% 64% Tanzania"` — OCR order, not a sentence — is currently indistinguishable from the report's own claims. It is now tagged: `derived_from` is `body`, `table`, `figure`, or `caption`, a figure gets exactly one chunk whose text is its caption plus labels, and a figure-derived chunk can be cited as a figure but never as the source of a number stated as fact.

The numbers decision follows from what the extraction can actually do. Docling's picture path is a captioning tool by design — `do_picture_description` stores three sentences of prose, and no Docling, Tika, or Unstructured setting emits series values. General vision models read printed labels well and unlabelled bar heights badly: ChartQA is saturated at 90.5% while ChartQAPro puts the same model at 55.8%, and CharXiv puts the best proprietary model at 47.1% against a human 80.5%. So OCR earns its place for findability — captions, axis labels, legends — and stops there. A number becomes an asserted number only when a figure record's value carries `source: dataset` and a `dataset_citation`. FAOSTAT is CC BY 4.0 with a mandated citation format and a prohibition on implying FAO endorsement; labelling a pixel-derived value as FAOSTAT would be both an accuracy error and a licence breach.

**Considered options:** VLM transcription of bar values (rejected as a source of record: no confidence, and the errors land exactly on unlabelled heights); OCR only (rejected: cannot read a height without a label, and cannot bind a legend to a series); no numbers at all (nearly chosen — the contract is written so that this is the behaviour until a resolver exists).

**Consequences:** until a dataset adapter is built, the report agent may say what a figure shows and may not state its values. Values live in a figure record returned with the chunk, never in the chunk text, so the embedded text stays honest and the trust gradient is visible: the chunk is evidence, the record is a claim with a provenance. The FAOSTAT adapter is accepted only when a fetched value reproduces its figure within tolerance; a figure that disagrees with its dataset is marked unverified rather than resolved in favour of either.
