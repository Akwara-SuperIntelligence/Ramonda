# Glossary Map

## Contexts

- [Ramonda](./GLOSSARY.md) — the platform vocabulary, shared by every client
- [AU Codex](./clients/au_codex/docs/GLOSSARY.md) — the first client's domain

## Relationships

- **AU Codex → Ramonda**: a Session is what a Job is about; Agenda Items become sections of one Artifact; an African Position is content the agent drafts and the Signer approves.
- **Ramonda → AU Codex**: no platform term refers to a client's vocabulary. A Session, an Agenda Item and a Standard Text exist only in the AU Codex glossary.
