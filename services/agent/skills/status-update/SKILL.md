# Status update

A status update is a **delta**, not a diary: what changed, what is blocked, what is next.

1. **Gather.** Call `recall` with the topic, the person, or the date. Read every hit.
   Done when each item you will report has a source and a date.
2. **Write three parts**, in this order: done, blocked, next. One line per item. Each line names a thing, not an activity.
   Done when every line reads as a fact a stranger could check.
3. **Close.** State the single next action and who owns it. If nothing needs the user, say so and stop.

Keep it under ten lines. Name each gap as `unknown`; do not guess.

Done when every item traces to a recall hit and the update fits on one screen.
